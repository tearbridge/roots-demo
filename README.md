# roots-demo · 华北村庄来历图（试作）

明初山西移民与华北村庄来历的交互地图。非商业试作。

- 首页输入县、村、姓：查村的来历（目前仅河北赵县逐村整理了 24 村）、同姓村名分布、文献记载
- 时间线：1167 / 元末 / 洪武 / 靖难 / 永乐 / 今天
- 村名线索：冀晋鲁豫京津 13 万村镇中名字带营、屯、卫、所、铺、堡、寨的村

数据与出处见页面「出处」。村镇点位与河流 © OpenStreetMap contributors (ODbL)；行政区界 DataV GeoAtlas；地形 AWS Terrain Tiles；地图库 Leaflet (BSD-2)。
